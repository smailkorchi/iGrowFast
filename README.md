# iGrowFast

iGrowFast is a web application for operators of Moroccan cash-on-delivery (COD) e-commerce businesses.

## Product focus

The project is designed to bring day-to-day COD operations into one workspace:

- Order processing and confirmation
- Parcel and delivery-status tracking
- Ad-spend and commission workflows
- Finance, payouts, and business administration
- WhatsApp sales conversations across teams and numbers

It is intended for sellers, media buyers, couriers, administrators, business owners, and WhatsApp agents. The main interface is French-first, with Arabic customer content and right-to-left (RTL) support.

## Project status

iGrowFast is actively under development. The list above describes the product scope; not every workflow should be assumed production-ready. The repository currently has no published releases or contribution guide.

## Technology

- React and TypeScript
- Vite
- Supabase JavaScript client

## Run locally

Requirements: Node.js and npm.

```sh
npm ci
npm run dev
```

See `package.json` for the available development, build, lint, and test scripts. Environment-specific configuration is not documented yet; do not put production credentials in the repository.
